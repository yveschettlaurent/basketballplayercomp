# Basketball Player Comparison Tool
This is my first ever C++ Project. It compares two basketball players based on their statistics and accomplishments, then compares the two and tells the user who's better.
## How it functions
- Takes the statistics of two basketball players
- Applies different weight to each statistic depending on its relevancy and in-real life importance
- Divides every statistic into groups to make inputting stats easier. The groups are:
  ### General Statistics
  - PPG
  - APG
  - RPG
  - SPG
  - BPG
  - TOV
  ### Efficiency
  - FG%
  - 3P%
  - FT%
  - TS%
  - Usage
  - Plus/Minus
  ### Legacy/Reliability
  - GP
  - Important Moments
  - Game Winners
  - Buzzer Beaters
  - Awards
  ### Ratings
  - Def Rating
  - Off Rating
    The program combines the values (with weights applied) into a player score for each player. Whoever has the higher player score is the better player, and the program outputs that.
## Current Version
- The current version has two players already set as an example, simply replace the statistics and names (but don't touch the weights, which are in parenthesis after the * symbols).
- The values must be inputted manually
